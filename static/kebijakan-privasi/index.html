Kebijakan Privasi

Terakhir diperbarui: 5 November 2026

VoiceMotion Studio menghargai privasi kamu. Halaman ini menjelaskan data apa yang kami simpan dan bagaimana data itu dipakai.

Data yang kami simpan

Nama, email, avatar, plan, jumlah kredit, dan data proyek yang kamu buat. Audio TTS disimpan sebagai cache agar pembuatan suara berikutnya lebih cepat.

Cara kami memakai data

Data dipakai untuk menjalankan akun, menyimpan proyek, menghasilkan audio, dan menampilkan status plan. Kami tidak menjual data ke pihak ketiga.

Layanan pihak ketiga

Login Google memakai OAuth Google. Suara dibuat dengan edge-tts atau Google Cloud Text-to-Speech. Prompt dikirim ke chatbot pilihanmu sendiri, bukan dari server kami.

Penyimpanan dan keamanan

Password akun email disimpan sebagai hash bcrypt. Sesi memakai JWT. Akses proyek dibatasi pada pemilik akun.

Hak kamu

Kamu bisa meminta salinan, koreksi, atau penghapusan data akun dengan menghubungi admin. Penghapusan akun menghapus proyek dan data terkait.

Cookie dan penyimpanan lokal

Kami memakai localStorage untuk token sesi, preferensi tampilan, dan status onboarding. Tidak ada cookie iklan.

Pertanyaan privasi? Hubungi admin melalui halaman harga atau email yang tertera di akunmu.
